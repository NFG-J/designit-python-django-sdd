Before you begin

Install Python 3.12 or 3.13 and an editor. This course uses Django 5.2; an existing AgentCMS repository should use its own documented versions. Some HTML knowledge is useful. Completely new to programming? Allow extra time for modules 1–5.

Progress is saved only in this browser when local storage is available. It does not sync across devices.
